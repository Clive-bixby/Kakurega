# Kakurega Frontend

React + TypeScript + Vite UI for Kakurega.

## Run locally

``` bash
npm install
npm run dev
```

The dev server runs on <http://localhost:5173> and proxies `/api` and `/storage` to
`http://localhost:8000` by default. Override the target with `VITE_API_PROXY_TARGET`.

## Build

``` bash
npm run build
```
